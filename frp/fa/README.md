## 📋 نمای کلی

این بخش مستندات جامع برای **FRP (Fast Reverse Proxy)** را شامل می‌شود، یک پروکسی معکوس قدرتمند که از پروتکل‌های **TCP, UDP, HTTP, HTTPS** پشتیبانی می‌کند.

**🔐 امن. ⚡ سریع. 🔧 انعطاف‌پذیر. 🌐 چندپروتکلی.**

---

## 🖥️ اطلاعات سرور

| جزئیات | مقدار |
|--------|-------|
| **آی پی سرور** | `2.144.21.218` |
| **پروتکل** | TCP + UDP |
| **احراز هویت** | مبتنی بر توکن |
| **محدوده پورت** | `8000-9000` (قابل پیکربندی) |
| **وضعیت** | 🔴 آفلاین (در حال حاضر غیرفعال) |

## 🚀 شروع سریع

### اتصال به سرور (کلاینت)

```bash
# اتصال TCP پایه
frpc tcp --server-addr 2.144.21.218 --server-port 7000 --token توکن_شما --local-port 8080 --remote-port 8080

# اتصال UDP
frpc udp --server-addr 2.144.21.218 --server-port 7000 --token توکن_شما --local-port 8080 --remote-port 8080
```

> ⚠️ **توجه:** سرور در حال حاضر آفلاین است. برای دسترسی با مدیر سرور تماس بگیرید.
