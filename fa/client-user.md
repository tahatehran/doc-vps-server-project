## 🤔 بور چیست؟

**بور** ابزاری است که به شما کمک می‌کند خدمات کامپیوتر محلی خود را با دیگران در اینترنت به اشتراک بگذارید. به عنوان یک تونل امن در نظر بگیرید که برنامه‌های محلی شما را به جهان متصل می‌کند.

### مثال ساده

```
کامپیوتر محلی شما → تونل بور → اینترنت → دیگران می‌توانند دسترسی داشته باشند
```

## 🚀 شروع سریع

### مرحله ۱: نصب بور

**لینوکس/macOS:**
```bash
curl -L -o /tmp/bore.tar.gz "https://github.com/ekzhang/bore/releases/download/v0.6.0/bore-v0.6.0-x86_64-unknown-linux-musl.tar.gz"
tar -xzf /tmp/bore.tar.gz -C /tmp
sudo install -m 755 /tmp/bore /usr/local/bin/bore
```

**ویندوز (PowerShell):**
```powershell
scoop install bore-cli
```

### مرحله ۲: اتصال به سرور

```bash
bore local 8080 --to 2.144.21.218:7835 --secret "رمز_شما"
```

همین! پورت محلی 8080 شما اکنون از طریق سرور قابل دسترسی است.

## ⚡ دستورات پایه

### اتصال به سرور

```bash
# فرمت پایه
bore local <پورت_شما> --to <آی_پی_سرور>:<پورت_سرور> --secret <رمز>

# مثال: به اشتراک‌گذاری برنامه وب محلی روی پورت 3000
bore local 3000 --to 2.144.21.218:7835 --secret "رمز_شما"
```

### درک دستور

| بخش | معنی | مثال |
|------|------|---------|
| `bore local` | شروع تونل محلی | `bore local` |
| `3000` | پورت محلی شما | `3000` |
| `--to` | اتصال به سرور | `--to` |
| `2.144.21.218:7835` | آدرس سرور | `2.144.21.218:7835` |
| `--secret` | احراز هویت | `--secret` |
| `"رمز_شما"` | کلید رمز شما | `"abc123..."` |

## 💼 کاربردهای رایج

### ۱. به اشتراک‌گذاری وب‌سایت محلی

```bash
# اگر وب‌سایتی روی localhost:3000 اجرا می‌شود
bore local 3000 --to 2.144.21.218:7835 --secret "رمز_شما"
```

### ۲. به اشتراک‌گذاری دیتابیس

```bash
# به اشتراک‌گذاری دیتابیس PostgreSQL محلی
bore local 5432 --to 2.144.21.218:7835 --secret "رمز_شما"
```

### ۳. به اشتراک‌گذاری هر سرویسی

```bash
# 8080 را با هر شماره پورتی جایگزین کنید
bore local 8080 --to 2.144.21.218:7835 --secret "رمز_شما"
```

## 🔧 عیب‌یابی

### مشکلات رایج

| مشکل | راه‌حل |
|---------|----------|
| `Connection refused` | بررسی کنید که سرور آنلاین باشد |
| `Authentication failed` | تأیید کنید که رمز شما درست است |
| `Port already in use` | پورت محلی متفاوتی انتخاب کنید |
| `Command not found` | بور را به درستی نصب کنید |

### دریافت کمک

اگر با مشکلاتی مواجه شدید:
1. وضعیت سرور را بررسی کنید
2. کلید رمز خود را تأیید کنید
3. پورت دیگری امتحان کنید
4. با مدیر سرور تماس بگیرید
